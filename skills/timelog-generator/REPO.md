## Workflow

### 1. Make Changes

Edit Python scripts, update documentation:

```bash
# Edit extraction formula
vim timelog_extract.py

# Update user guide
vim README.md

# Test changes
make test
```

### 2. Commit to Git

```bash
git add timelog-generator/
git commit -m "feat(timelog): improve hour estimation"
git push
```

### 3. Deploy to System

```bash
make install
# Now /timelog works in Claude sessions
```

### 4. Update System Later

```bash
# After making changes locally
make install    # Copies files to ~/.claude/skills/
```

## Release Process

To release a new version:

1. Update `.version` file with new version number
2. Update `TECHNICAL.md` with any algorithm changes
3. Update `README.md` with new features/changes
4. Run `make test` and `make trial`
5. Commit with message: `chore: release vX.Y.Z`
6. Run `make install`
7. Tag: `git tag vX.Y.Z && git push --tags`
