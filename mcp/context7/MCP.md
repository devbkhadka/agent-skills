# Context7 MCP Server

Provides real-time, up-to-date documentation and semantic code search for libraries and frameworks.

## Usage
- Transport: `stdio`
- Command: `npx -y @upstash/context7-mcp`

## Environment Variables
- `CONTEXT7_API_KEY` (required): API Key from context7.com.
- `CONTEXT7_TIMEOUT` (optional): Request timeout in milliseconds (default: 5000).
